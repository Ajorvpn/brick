# Android Native Module

This directory is reserved for the Android-native VPN integration. Phase 3
will populate it with the Kotlin `VpnService` lifecycle, Pigeon-generated
platform channels, and the libbox AAR bridge described in
[ARCHITECTURE.md](../../AI_ROLES/ARCHITECTURE.md), Sections 3 and 3.5.

This Phase 0 scaffold intentionally contains no Gradle files, Kotlin source,
VPN service, platform-channel code, or native build configuration.
